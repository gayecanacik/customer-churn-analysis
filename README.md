# Customer Churn Analysis

## Overview

This project analyzes customer churn patterns and identifies high-risk customer segments using Excel, SQL, Python, and Power BI.

## Tools

- Excel
- SQL
- Python
- Power BI

## Key Findings

- Overall churn rate: 47.37%
- Customers with monthly contracts have the highest churn rate.
- Higher payment delays are strongly associated with churn.
- Customers with more support calls show higher churn.
- Low-usage customers represent a high-risk segment.
- Customers aged 56–65 have the highest churn rate among age groups.

## Business Recommendations

- Prioritize retention campaigns for high-risk customers.
- Investigate customers with high payment delays.
- Improve engagement among low-usage customers.
- Review retention strategies for monthly-contract customers.
- Monitor customers with frequent support interactions.
